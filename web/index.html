Nur Vorschau

Dieser Browser kann kein Web Bluetooth. Auf Android: Chrome benutzen. Auf dem iPhone: die App „Bluefy“ benutzen. Die Vorschau funktioniert trotzdem.

Das Foto füllt das ganze Display, überstehende Ränder werden abgeschnitten. Senden dauert ein paar Sekunden.

Beim ersten Senden fragt der Browser nach dem Clip. Er muss eingeschaltet und in der Nähe sein.
